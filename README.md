## 🛠️ Persiapan Lingkungan (Setup Environment)

Proyek ini dikelola menggunakan [`uv`](https://github.com/astral-sh/uv).

### 1. Sinkronisasi Dependencies
```bash
uv sync
```

### 2. Menjalankan Jupyter Notebook
```bash
uv run jupyter notebook
# atau
uv run jupyter lab
```
